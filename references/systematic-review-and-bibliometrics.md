# 系统综述与文献计量的实施边界

用户明确要求系统综述、Meta 分析或文献计量时加载。普通背景综述不自动套完整筛选流程，计量网络也不能替代文献内容分析。

## 系统综述

1. 明确综述问题、适用研究类型、纳入排除标准及计划采用的综合方式。说明哪些决定预先作出，哪些在研究中调整。
2. 记录数据库与平台、完整检索式、时间范围、检索日期和补充检索来源。工具生成检索式后，应在目标数据库验证语法和结果。
3. 保存题录、去重规则、筛选决定、全文获取状态及排除理由。同一研究可能有多篇报告，不能直接把题录数当成研究数。
4. 按研究类型选风险偏倚或质量评价工具。先核对工具适用范围和当前说明，再设计提取表，不能只凭工具名称匹配。
5. 根据对象、设计、指标和效应量的可比性选择叙述综合或统计合并。没有实际提取与分析，不填造效应量、异质性指标或森林图。

PRISMA 是报告指南。按新综述或更新综述、检索来源选择相应流程图，核对记录、报告与研究的数量及排除理由；一张流程图本身不能证明综述完整或无偏。参见 [PRISMA 2020](https://www.prisma-statement.org/prisma-2020) 与[官方流程图](https://www.prisma-statement.org/prisma-2020-flow-diagram)。

可用记录字段：数据库/查询/检索日期/记录 ID/DOI/去重组/题摘决定/全文状态/全文排除理由/研究 ID/提取位置。没有执行检索时只提供模板，数量留空。

检索报告还应核对 [PRISMA-S](https://www.prisma-statement.org/prisma-search) 的适用条目，保存各平台的实际检索式、限制和日期。轻量检索与完整记录的分工见 `search-and-evidence-record.md`。

## 文献计量

使用真实数据库导出的题录，记录来源、导出日期、字段、检索式和去重处理。先检查作者、机构及关键词的同名异写，再选择共现、合作、共被引或文献耦合等分析。

说明时间切片、计数方式、阈值、归一化、聚类和标签解释的选择。结果只代表本次检索与数据库覆盖范围，发文量、引文数或聚类名称不能直接等同于研究质量或创新价值。

工具按数据格式和分析任务选择，并核查所用版本的文档。bibliometrix 属于 R 生态，不能照旧模板写成 Python 包，参见 [bibliometrix 官方说明](https://www.bibliometrix.org/software/)。CiteSpace、VOSviewer 或其他工具的参数按实际任务记录，不凭通用模板声称已完成分析。

## 交付与核对

方案任务交检索与分析计划、记录模板和待确定项。执行任务交真实记录、筛选数量、提取结果、分析设置及对应文件。各阶段数量能对账，图表能追溯到原数据，结论不超出覆盖范围。
